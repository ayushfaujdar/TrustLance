# Security Policy

## Supported Versions

TrustLance is under active development. Security fixes are applied to the latest version on the default branch; no release support schedule is currently defined.

## Reporting a Vulnerability

Do not report suspected vulnerabilities in public issues or pull requests. Use GitHub's **Report a vulnerability** option on this repository to send a private report to the maintainers. Include the affected component, impact, and steps to reproduce where safe. Please allow maintainers time to investigate and coordinate a fix before public disclosure.

Do not include real credentials, personal data, or production payment details in a report.
